# GSAP Wizard

**GSAP Wizard** is a modern and interactive landing page built using **HTML, CSS, JavaScript, and GSAP (GreenSock Animation Platform)**. The project focuses on creating smooth animations, engaging scroll effects, and visually appealing transitions to deliver an immersive user experience.

I built this project to explore GSAP animations and improve my skills in creating dynamic and interactive web interfaces.

---

## Features

- Smooth animations powered by GSAP
- Scroll-based animation effects
- Interactive and engaging user interface
- Modern and responsive design
- Optimized for desktop and mobile devices
- Cross-browser compatibility

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (GreenSock Animation Platform)

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/Rohit-walvekar/gsap-wizard.git
```

### 2. Navigate to the project folder

```bash
cd gsap-wizard
```

### 3. Open the project

Simply open the **index.html** file in your browser.

Or, if you're using **VS Code**, install the **Live Server** extension and click **Go Live**.
